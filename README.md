COVID-19 Deaths Analysis
Project Overview
This project analyses global COVID-19 mortality data to compare total recorded deaths across continents and identify the most affected regions.
Business Question
Which continents were most affected by COVID-19 deaths and what factors influenced the differences?
Tools Used
Python, Pandas, Matplotlib, Google Colab
Key Findings
Europe recorded the highest total COVID-19 deaths followed by North America and Asia. Oceania had the lowest recorded deaths. Differences across continents reflect variations in healthcare capacity, population density, government response strategies, and data reporting practices.
Dataset
Source: Our World in Data
